# Mumzworld AI - Baby Shower Gift Finder 🍼✨

An end-to-end, AI-native concierge frontend prototype designed to help users discover the perfect baby shower gifts. Built as a response to the **Mumzworld AI-Native Internship (Track A)** take-home challenge.

## 🎯 Overview

This project simulates a **Retrieval-Augmented Generation (RAG)** system and agentic workflow. The AI concierge understands user intent, gifting context, product safety, and age-compatibility to provide highly personalized gift recommendations from a simulated Mumzworld product catalog. 

The application is built completely with vanilla web technologies to ensure a zero-dependency, plug-and-play experience.

## ✨ Features

- **Conversational AI Interface**: A premium, chat-based UI that simulates a natural interaction with an AI concierge.
- **Simulated RAG Pipeline**: The logic filters through a mock product catalog based on user queries, matching for keywords like "budget", "safe", "coworker", and "premium".
- **Safety & Age-Compatibility**: Prioritizes crucial parenting metrics. Displays custom badges for certified safe products and highlights age restrictions.
- **Dynamic Glassmorphism UI**: A visually stunning, modern interface featuring blur effects, soft gradients, and interactive micro-animations to create a premium shopping experience.
- **Quick Prompts**: Built-in scenario buttons (e.g., "Coworker Gift < $50", "Safe Toys 6mo+") to easily demonstrate the AI's capabilities.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure and accessible layouts.
- **CSS3 (Vanilla)**: Advanced styling utilizing custom properties (variables), Flexbox, CSS animations, and glassmorphism techniques. 
- **JavaScript (ES6+)**: Vanilla JS handles DOM manipulation, event listeners, typing indicator simulations, and the core recommendation algorithm.
- **FontAwesome**: For scalable vector icons.
- **Google Fonts**: Utilizing the 'Outfit' font family for a modern aesthetic.

## 🚀 Getting Started

Because this project is built using vanilla web technologies, there are no packages to install or build steps required.

1. Clone or download this repository.
2. Navigate to the project folder.
3. Simply double-click the `index.html` file to open it in your default web browser.

## 💡 Usage

1. **Start a Chat**: Type a request into the chat box (e.g., "I need a budget gift for a coworker" or "What are some safe toys for a 1-year-old?").
2. **Use Quick Scenarios**: Click any of the pre-defined scenario buttons in the sidebar to instantly see how the system handles complex gifting contexts.
3. **View Recommendations**: The AI will "process" your request and return a tailored response alongside rich product cards featuring prices, ratings, and safety certifications.
